# MiNiGeMi\n\nMiNiGeMi is a modern browser extension designed to integrate seamlessly into your daily browsing experience. By utilizing the side panel API, it offers a persistent interface for tools, AI interactions, or data tracking without interrupting your main web content.\n\n## Features\n\n- **Persistent Sidebar**: A dedicated `sidebar.html` that stays open while you navigate different websites.\n- **Background Processing**: Leverages `background.js` for handling messaging, long-running tasks, and extension state.\n- **Lightweight Logic**: Client-side interactivity powered by a focused `sidebar.js`.\n- **Manifest V3**: Built using the latest extension standards for security and performance.\n\n## File Structure\n\n- `manifest.json`: Defines the extension metadata, permissions, and entry points.\n- `background.js`: The service worker managing extension lifecycle events.\n- `sidebar.html`: The visual structure of the side panel interface.\n- `sidebar.js`: The JavaScript logic that powers the sidebar interactions.\n\n## Installation\n\n1. **Download** or clone this repository to your local machine.\n2. Open your browser and go to the Extensions management page (e.g., `chrome://extensions` for Chrome or `edge://extensions` for Edge).\n3. Enable **Developer mode** using the toggle in the top-right corner.\n4. Click the **Load unpacked** button.\n5. Select the `MiNiGeMi` folder from your file explorer.\n\n## Usage\n\nOnce installed, you can open the sidebar by clicking the extension icon in your browser toolbar or through the browser's side panel menu. The UI defined in `sidebar.html` will appear, allowing you to interact with the extension features while you browse.
